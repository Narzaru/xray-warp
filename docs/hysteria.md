# Hysteria2 — транспорт для каналов с потерями

xhttp работает поверх TCP. На канале, где теряется заметная доля пакетов (мобильные сети, особенно при активной фильтрации), TCP обрушивает окно перегрузки, и скорость падает в разы — это свойство алгоритма, ни `cubic`, ни `BBR` не спасают.

Hysteria2 использует QUIC поверх UDP с алгоритмом Brutal: он удерживает заданную полосу при потерях вместо отступления. На маршруте с 15–25% потерь разница кратная.

Транспорт изолирован: свой контейнер, `:443/udp`, свой пароль. 3x-ui, XRay, sslh и существующие клиенты не затрагиваются; `443/tcp` и `443/udp` — независимые порты.

## Запуск

В `.env`:

```bash
HYSTERIA=on
```

и `./setup-3xui.sh`. Скрипт сгенерирует пароль, допишет его в `.env`, соберёт конфиг из шаблона и поднимет контейнер.

Пароль генерируется один раз: при повторном запуске заданное значение не трогается, и переустановка не сбрасывает доступ клиентам. `config/hysteria/config.generated.yaml` содержит пароль и в git не попадает.

Не забудьте открыть `443/udp` в фаерволе хостера.

## Клиенты

Пароль один на всех. Ссылку скрипт печатает в конце установки:

```
hy2://ПАРОЛЬ@yourdomain.com:443/?sni=yourdomain.com#имя-профиля
```

Показать повторно:

```bash
source .env
echo "hy2://${HYSTERIA_PASSWORD}@${DOMAIN}:443/?sni=${DOMAIN}#${DOMAIN}-hy2"
```

Сменить пароль (ссылка утекла) — стереть `HYSTERIA_PASSWORD` из `.env` и перезапустить скрипт. Ссылка меняется **у всех сразу**: отозвать доступ одному человеку нельзя. Для раздельного доступа есть режим `userpass` — в `config/hysteria/config.yaml` вместо `type: password` задаётся список логинов и паролей, ссылка вида `hy2://ЛОГИН:ПАРОЛЬ@...`.

- **v2rayNG Hysteria2 не поддерживает** — нужен Hiddify, NekoBox или sing-box.
- После импорта задайте **Upload / Download Mbps** чуть ниже реальной скорости канала — без этого Brutal не включится. Завышать нельзя: клиент зальёт канал сверх ёмкости и сам создаст потери.
- **IPv6.** Если на сервере нет IPv6, в клиенте выставить **IPv6 Mode = Disable**. Иначе туннель принимает IPv6-соединения, которые сервер не может набрать, браузер не переключается на IPv4, и сайты с IPv6 (прежде всего Google) висят до таймаута.

## Удаление

`HYSTERIA=off` в `.env` и перезапуск скрипта, либо вручную:

```bash
docker compose -f docker-compose.yml -f docker-compose.hysteria.yml rm -sf hysteria
rm -f config/hysteria/config.generated.yaml
```
